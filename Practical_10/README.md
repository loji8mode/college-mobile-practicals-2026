# Практична № 10 — навігація

Редактор передає текст, розмір і колір через конструктор PreviewScreen. Navigator.push<bool> очікує результат: Ok повертає true, Cancel — false, AppBar та системний Back — null. На редакторі з’являється відповідний AlertDialog.

## Запуск

```sh
flutter pub get
flutter test
flutter run
```

Flutter 3.47.9, Dart 3.13.7. Аналіз: `dart analyze lib test`.

Початковий текст можна редагувати. Розмір 12–60; синій, червоний або зелений колір. Контролер звільняється в dispose, після await перевіряється mounted.

Чотири widget-сценарії перевіряють текст, розмір 36, червоний колір, окремо результати Ok, Cancel, стрілки AppBar та системного Back, а також збереження тексту після повернення.
