# Практична № 7 — Stateless і Stateful

Пункт LCloud 8, варіант 1. Червоний Container з незалежними шириною й висотою та заокругленням лише верхнього правого кута.

## Запуск

```sh
flutter pub get
flutter test
flutter run
```

Перевірено з Flutter 3.47.9 і Dart 3.13.7. Аналіз: `dart analyze lib test`.

Ширина та висота: 50–260 логічних пікселів, початково 150. Радіус: від 0 до половини меншого розміру, автоматично обмежується при зменшенні ширини або висоти. LabeledSlider — окремий StatelessWidget з value та onChanged; стан належить ConfiguratorPage.

Чотири widget-тести: незалежні розміри й єдиний кут, зменшення допустимого радіуса, справжній drag повзунка, два малі розміри вікна без переповнення.
