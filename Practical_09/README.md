# Практична № 9 — форми та валідація

Три екрани: вхід, реєстрація та відновлення пароля. Form з GlobalKey<FormState>, TextFormField та AutovalidateMode.onUserInteraction. Дії показують локальне підтвердження лише після успішної валідації.

## Запуск

```sh
flutter pub get
flutter test
flutter run
```

Flutter 3.47.9, Dart 3.13.7. Аналіз: `dart analyze lib test`.

Правила: усі поля обов’язкові; email перевіряється регулярним виразом для поширеного формату; пароль має щонайменше 7 Unicode code points, пробільний пароль відхиляється. Підтвердження пароля має точно збігатися. Паролі можна показати або приховати окремими кнопками. Значення пароля не виводиться у діалозі.

Тести перевіряють межу 6/7 символів, Unicode, порожні та неправильні значення, приховування пароля, блокування некоректних форм і успіх усіх трьох коректних форм.

Логотип із шаблону Flutter; ліцензія в assets/FLUTTER_LICENSE.txt.
