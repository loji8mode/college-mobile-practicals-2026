Три валідовані форми надсилають лише демонстраційні дані до https://valentyn32ist-lab12-20261123.requestcatcher.com/. LogInterceptor журналює URL, метод і відповідь; паролі в журнал тіла не виводяться. Показано індикатор, блокування повторного натискання, SnackBar успіху й окремі повідомлення для тайм-ауту, HTTP-помилок і з’єднання. Кнопка у верхній панелі відкриває типізований список Post з JSONPlaceholder, стани завантаження, помилки й повтору.

Запуск: flutter pub get; flutter run. Перевірка: dart analyze lib test; flutter test. Збірка: flutter build apk --release.

Request Catcher є навчальним приймачем, а не сервісом справжньої автентифікації. Використовуйте тільки демонстраційні дані. Логотип Flutter походить зі стандартних ресурсів Flutter; ліцензію збережено в корені репозиторію.
