# Практична № 6 — базові віджети

Пункт LCloud 7. Окремий Flutter-застосунок з екранами входу, реєстрації й відновлення пароля. Кнопки демонструють локальні AlertDialog; мережевого сервісу на цьому етапі немає.

## Запуск

```sh
flutter pub get
flutter test
flutter run
```

Перевірено з Flutter 3.47.9 і Dart 3.13.7. Статичний аналіз: `dart analyze lib test`.

Тест охоплює введення, приховування пароля, діалоги трьох дій, обидва переходи та повернення зі збереженням логіна.

Логотип — стандартний значок проєкту з шаблону Flutter. Ліцензія Flutter збережена в assets/FLUTTER_LICENSE.txt.
